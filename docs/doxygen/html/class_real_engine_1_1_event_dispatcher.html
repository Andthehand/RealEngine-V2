Dispatches the stored event to the given handler if it matches type T.

Usage example:

EventDispatcher dispatcher(event);
dispatcher.Dispatch<WindowCloseEvent>([](WindowCloseEvent& e) {
// handle the event
return true; // mark event as handled
});
